# Middleware de Seguridad y Autorización

Este proyecto implementa un middleware para manejar procesos de seguridad en una API.

El middleware se encarga de interceptar las solicitudes realizadas a la aplicación y verificar que el usuario tenga los permisos necesarios para acceder a los recursos.

## Funciones principales

- Validar solicitudes antes de llegar a los controladores.
- Gestionar autorización de usuarios.
- Proteger endpoints de la API.

## Tecnologías

- .NET
- ASP.NET Core
